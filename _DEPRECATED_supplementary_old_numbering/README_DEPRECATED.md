## What is in here

`FigureS1`–`FigureS8` (PNG + PDF) plus `Supplementary_Figure_Captions.txt`. This is an
**older supplementary-figure scheme** that does **not** correspond to the current
Additional file 1 of the manuscript, whose supplementary figures are **Fig. S1–S6**

model SNP counts; direction-consistency sensitivity; endpoint calibration and positive control).

There is no one-to-one mapping to the current set — the old series has eight members and
different content, so the files are **not** simply renumbered copies of the current ones.

finalized submission set (PNG 600 dpi RGB + vector PDF + `*_caption.txt` matching the captions
embedded in Additional file 1). See `figures/README_figure_set.md`.
