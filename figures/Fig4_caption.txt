Fig. 4. Axis-resolved source-discordance decomposition. Comparison of the eQTL resource/sample-size axis with the tissue-context axis. (a) Spearman ρ with Fisher-z 95% confidence intervals for the three decomposition arms defined in Table 3b, plotted on the full-pair inputs of each arm (panel-only, n = 159 gene–phenotype pairs; tissue-only, n = 138; dual-mismatch, n = 198). (b) Forest plot of Δρ (dual minus single-axis) on the 45-gene common universe (n = 135 gene–phenotype pairs), derived from a paired gene-cluster bootstrap (B = 5,000, seed 20260915), showing 95% confidence intervals and two-sided bootstrap P values; the paired differences in direction consistency (dual minus panel-only −3.0 percentage points; dual minus tissue-only +2.2) are reported in the text and in Additional file 1: Table S15. Panels (a) and (b) label the three arms by their design contrasts rather than by abbreviated axis names, because the two single-axis arms differ in bootstrap P value owing to their different pairing against the dual arm.
