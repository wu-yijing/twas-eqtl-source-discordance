Figure S5. Direction consistency sensitivity analysis. Direction consistency between GTEx v8 and eQTLGen (percentage of pairs showing the same effect direction) as a function of an increasing minimum |Z| threshold applied to both eQTL sources. Because the primary 96-pair comparison contains only non-candidate and T2DM control genes — candidate cross-source agreement was assessed separately on GTEx Nerve_Tibial (Fig. 5) — only non-candidate and T2DM control groups are shown. Thresholds shown are 0, 0.5, 1, 1.5, 2, 2.5 and 3; strata with fewer than five pairs are omitted. The dashed line marks the within-arm empirical null (63.6%; pairs in which neither source shows association), which is the reference used throughout; no inference is drawn against a 50% level, because the empirical-null concordance exceeds 50% whenever the two sources share a GWAS input (Methods). The curves are computed from the 96 gene-phenotype pairs of Additional file 1: Table S12. Direction consistency rises with signal strength, reaching 75.6% at min|Z| ≥ 0.5 (41 testable pairs) and 88.2% at min|Z| ≥ 1.0 (17 pairs). Beyond that the strata are too small to be stable: all five pairs at min|Z| ≥ 1.5 and the single pair at min|Z| ≥ 2.0 are direction-consistent, and no pair survives a threshold of 2.5 because the largest min(|Z_GTEx|, |Z_eQTLGen|) in this arm is 2.40. Values at each threshold are tabulated in Additional file 1: Table S20.
